# Local references in MDX

Use this procedure when an instruction links to a file or heading in the same
repository.

## Verify a local reference

<aside>

Resolve the path from the directory containing the link. If the link has a
fragment, verify that the destination heading still exists.

</aside>

From the project root, run the offline check:

```sh
mise run md:links
```

A zero exit status means the checked references resolve. For the full gate,
follow the [Markdown validation procedure](../docs/example.md#check-a-documentation-change).
