# Python Standards Tester

One typed package with example and Hypothesis property tests exercises the
Python standards profile through its copied mise wiring and drift-checked
Dagger wrapper: strict static analysis, branch coverage, wheel and source
distribution builds, and the mutmut sweep gated by the committed
`.mutmut-floor` ratchet.

Contract tests drive the suppression policy, the mutation-report and
Interrogate validators, and the mutation transaction lock through their real
process boundaries. Pinned Ruff and Bandit probes prove that only mutmut's
generated root tree is excluded while nested `mutants/` source directories stay
checked.

Real Python projects can run `mise run py:deep` when they want the heavier
analyzer profile.
